# Unix Glob Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为带路径参数的命令增加 `*`/`?`/`[]`/`**` 展开，逻辑集中在 `common/Expand-UnixGlob.ps1`，无匹配静默跳过。

**Architecture:** `Test-UnixGlobPattern` 检测通配；`Expand-UnixGlob` 按路径段 BFS 展开（`**` 展开为当前及所有子目录）。各命令在取得路径列表后调用 `Expand-UnixGlob`。`which`、`grep` 模式、`find -name` 不展开。

**Tech Stack:** PowerShell 5+、`WildcardPattern`、`Get-ChildItem -LiteralPath`

## Global Constraints

- 无匹配静默跳过
- 无通配符时原样返回，不做存在性检查
- `**` 为完整路径段，匹配零或多层目录
- 不展开 `which` / `grep` 正则 / `find -name` 模式

## File Structure

| 文件 | 职责 |
|------|------|
| `src/common/Expand-UnixGlob.ps1` | `Test-UnixGlobPattern`、`Expand-UnixGlob` |
| `src/load.ps1` | 注册加载 |
| 各命令 `*.ps1` | 路径列表后调用展开 |
| `COMMANDS.md` | 通配符说明 |

### Task 1: 实现 Expand-UnixGlob

**Files:**
- Create: `src/common/Expand-UnixGlob.ps1`
- Modify: `src/load.ps1`（在 `Merge-UnixFlagLetters.ps1` 后加入加载项）

**Interfaces:**
- Produces: `Test-UnixGlobPattern([string]$Pattern) -> [bool]`；`Expand-UnixGlob([string[]]$Path) -> [string[]]`

- [ ] **Step 1: 编写 Expand-UnixGlob.ps1**

实现要点：
- `Test-UnixGlobPattern`：含 `*`、`?`，或成对 `[...]` 则 true
- `Expand-UnixGlob`：逐参数；非通配原样加入；通配则分段 BFS
- 相对路径起点为 `(Get-Location).Path`；绝对路径用 `GetPathRoot`
- 段为 `**`：把当前目录及其下所有子目录加入下一轮
- 段含通配：在当前目录下用 `WildcardPattern`（IgnoreCase）匹配 Name
- 段为字面：`Join-Path` + `Test-Path -LiteralPath`
- 匹配结果用 `FullName`；全程 `SilentlyContinue`

- [ ] **Step 2: 注册 load.ps1**

在 `$script:UucipLoadOrder` 的 `common\Merge-UnixFlagLetters.ps1` 后增加：
`'common\Expand-UnixGlob.ps1'`

```powershell

# 在临时目录造文件后测 *、?、[]、**、无匹配静默、字面原样
```
